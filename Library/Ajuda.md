# Comandos pessoais

No Desktop, sincronize/recarregue e execute **Integrações: Conectar Desktop pela Tailscale** uma vez por computador. Use o token SilverBullet próprio desse computador, não chaves Zotero/Vikunja/Readeck. A credencial fica no clientStore local, fora das notas/Git (não é Keychain). Para remover: **Integrações: Desconectar este computador**; revogue também o token no Dashboard.

- Daily: Abrir hoje
- Vikunja: Sincronizar Daily atual
- Vikunja: Projeto da tarefa atual
- Vikunja: Todas tarefas
- Vikunja: Tarefas de hoje
- Zotero: Buscar biblioteca (`/cite`)
- Readeck: Buscar bookmarks (`/readeck`)

Todas as tarefas salvas em `Daily/YYYY-MM-DD` vão ao Inbox, salvo projeto explícito. Apagar uma linha não apaga a tarefa remota.

Para o diário, abra [[Daily]] na página inicial e clique **Abrir Daily de hoje**.
O destino é `Daily/AAAA-MM-DD`, não uma página com código de implementação.

Zotero e Readeck: a lista muda enquanto você digita (pausa de 350 ms). Deixe vazio para ver itens; use ao menos dois caracteres para filtrar. Setas navegam e Enter seleciona; Escape fecha.

Ao citar pelo Zotero, escolha **Citar em APA**: a citação autor–ano é um link para a nota bibliográfica, importada se ainda não existir. A referência completa aparece em **Referências** no final da nota. No Readeck, escolha inserir link ou importar/abrir a nota com highlights.
